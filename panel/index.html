Traffic Chaff & DPI Shield

          

          
Anti-censorship and flood defense. Chaff fills idle timing gaps with randomized ping packets. DPI shield protects reverse ports from active scanner floods.


          

            
            

              
              
              —
            

            
Idle-gap filler creates random dummy pings across the GRE tunnel. Default is OFF.

              60/sec (burst 120)
            

            
Uses iptables hashlimit per source IP to protect reverse ports against aggressive port scanners without throttling normal user connections. Default is OFF.
